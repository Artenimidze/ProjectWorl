## 🧠 Общая схема выполнения всех лабораторных

1. **Получение датасета** — скачать/получить нужный датасет
2. **Предобработка данных** — структура, пропуски, формат, нормализация
3. **Подготовка выборок** — разделение на train/test, формирование последовательностей/изображений
4. **Создание нейронной сети** — выбор архитектуры (Dense, CNN, LSTM, Autoencoder)
5. **Обучение модели** — запуск, настройка параметров
6. **Проверка работы** — тестирование, предсказания
7. **Расчёт метрик и анализ** — графики, ошибки, выводы
8. **Оформление** — цель, датасет, алгоритм, код, результаты, вывод

## 📂 Структура репозитория

- `Labs/` — папки с лабораторными работами (код, ноутбуки, отчеты)
- `Plans/` — планы и вспомогательные материалы
- `datasets` — папки с данными для датасетов
